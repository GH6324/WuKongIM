## Standards 审查

固定初始范围：`ab1ced72450658ba85399b03293ac37c20278721...80896a355257d6188d2e517d1ac9792a2c453841`。确认 1 项 P2：15 条历史页只差一条 lookahead 时，续读仍请求 1,024 条；较大正文可超过远端帧上限。续读现按剩余可见需求收紧，保留 64 波／五秒预算。模拟 64 MiB 帧预算的回归先失败后通过；该回归不等于真实发送一个 128 MiB 帧。

合并 `93633f2db907f36065f976ba1576de073429d923` 后复查确认 2 项 P2：收敛的身份轮必须等齐已观察的全部副本；批量任务游标不得越过因前项超时而尚未开始的后项。分别改为该轮要求全部已观察副本、每次只取一个当前归属的任务。任务去重使用频道、类型、任务 ID 的完整身份。延迟副本集成回归及无真实等待的取消／同 ID 跨频道单元回归覆盖这些条件。
